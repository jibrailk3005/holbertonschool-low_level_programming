## Structures and Typedef in C

I am currently working on the Holberton School **C - Structures, typedef (0x0d)** project to understand how structures and typedef work in C. A **structure (`struct`)** is a user-defined data type that allows us to group different types of variables under one name. It is useful for storing related information together, such as a dog's name, age and owner. Each variable inside a structure is called a member, and we can access these members using the dot (`.`) operator or the arrow (`->`) operator when working with pointers to structures. **Typedef** is a keyword that creates an alternative name (alias) for an existing data type, making code shorter, simpler and easier to read. When used with structures, `typedef` allows us to declare structure variables without repeatedly writing the `struct` keyword.
