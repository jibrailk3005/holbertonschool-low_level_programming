# C - Pointers, Arrays and Strings

This project focuses on understanding pointers, arrays and strings in C. It explores how pointers store memory addresses, how arrays organise data, and how strings are stored and manipulated in memory. Through practical exercises, we learn how to access and modify values using pointers, work with arrays, and perform basic string operations. All functions must follow Betty coding standards and compile using GCC with the required flags. The project also reinforces memory management concepts, variable scope, and the relationship between pointers and arrays.
