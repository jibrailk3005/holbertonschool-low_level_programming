# 0x0E. C - Function Pointers

## Description

This project introduces function pointers in C and how to use them to pass functions as arguments (callbacks).

## Learning Objectives

- Understand what function pointers are and how to use them.
- Understand that a function pointer holds the address of a function.
- Understand where function pointers point in virtual memory.
- Learn how to declare, pass and call function pointers.
