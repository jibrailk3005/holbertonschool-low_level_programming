## Learning Objectives

In this project, I learned about variadic functions in C and how to work with functions that accept a variable number of arguments.

I explored the use of `va_list`, `va_start`, `va_arg`, and `va_end` to access and process additional arguments. I also learned how to use the `const` type qualifier to protect data from being modified.

Through practical exercises, I gained experience handling different data types, working with pointers, and printing arguments using variadic functions.
